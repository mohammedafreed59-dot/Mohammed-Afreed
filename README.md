# Patient Health Records Analysis

## Project Overview
This project focuses on cleaning, analyzing, and visualizing patient health records to identify patterns in patient health and disease status.

## Objectives
- Clean and standardize patient health data.
- Handle missing values and inconsistent records.
- Analyze patient demographics and health indicators.
- Build an interactive dashboard to explore disease-related patterns.

## Tools Used
- Microsoft Excel — Data cleaning and exploratory data analysis.
- Microsoft Power BI — Interactive dashboard and data visualization.
- GitHub — Project storage and version control.

## Key Analysis Areas
- Patient demographics by age, gender, and city.
- Disease status across different patient groups.
- Diabetes and smoking status in relation to disease status.
- Cholesterol-level categories and patient health indicators.

## Dashboard Features
- KPI cards for patient counts and health indicators.
- Interactive slicers for gender, city, and disease status.
- Visual comparisons by age group, gender, city, diabetes, smoking, and cholesterol.

## Important Note
Disease status is missing for some records. These records are treated as unknown rather than classified as either having or not having a disease.
